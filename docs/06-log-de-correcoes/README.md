## Como registrar uma correção nova

Crie um arquivo `AAAA-MM-DD-assunto.md` com quatro seções: **o sintoma** (o que
o usuário via), **a causa raiz** (o porquê técnico), **a correção** e **o que
ficou de aprendizado**. A última é a que mais vale com o tempo.
